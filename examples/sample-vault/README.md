# Sample Vault

Este Vault contém apenas exemplos fictícios para demonstrar o funcionamento do Second Brain.

Estrutura:

```text
sample-vault/
├── 00 Caixa de Entrada/
├── 10 Memória/
├── 20 Projetos/
├── 30 Conhecimento/
├── 40 Áreas/
├── 50 Referências/
├── 60 Diário/
├── 90 Legado/
└── 99 Arquivo/
```

Use esse conteúdo para testar indexação e busca semântica sem expor dados pessoais.

Exemplos de perguntas:

```text
Qual banco vetorial o projeto utiliza?
Qual é a função do coração?
Como o Second Brain organiza as notas?
```
