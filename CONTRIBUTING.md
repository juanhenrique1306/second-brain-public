# Contributing

Contribuições são bem-vindas.

## Antes de contribuir

Leia `README.md` e `SECURITY.md`.

Nunca inclua em commits tokens, senhas, chaves de API, conteúdo pessoal do Vault, arquivos `.env`, dumps de banco, certificados ou chaves privadas.

## Fluxo recomendado

```bash
git checkout -b feature/minha-melhoria
git add .
git commit -m "feat: descreva sua alteração"
git push origin feature/minha-melhoria
```

Depois abra um Pull Request.

## Padrão de commits

```text
feat:     nova funcionalidade
fix:      correção
docs:     documentação
refactor: refatoração
test:     testes
chore:    manutenção
security: melhoria de segurança
```

## Pull Requests

Informe o que foi alterado, por que, como testar, impactos de segurança e eventuais breaking changes.

## Segurança

Não abra issue pública contendo detalhes exploráveis de vulnerabilidades. Consulte `SECURITY.md`.
